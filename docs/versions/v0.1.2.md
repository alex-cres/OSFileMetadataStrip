## Fixed

- `StripImageMetadata` now captures the image comment field in `ExtractedMetadata` under the key `"comment"`. The comment was already being stripped by `frame.Strip()` but was never recorded in the audit output. Affects GIF (Comment Extension), PNG (tEXt Comment chunk), JPEG (COM marker), and any other format that Magick.NET exposes via `image.Comment`.

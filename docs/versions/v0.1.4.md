## Changed

- **BMP treated as passthrough**: BMP files have no standard metadata containers (no EXIF, IPTC, or XMP support). BMP is now detected by magic bytes (`0x42 0x4D`) before the Magick.NET image path and returned unchanged with `IsPassthrough = true`, `RemovedEntryCount = 0`, and `ExtractedMetadata = "[]"`. Previously BMP went through a redundant re-encode that produced no security benefit.
- **README updated**: BMP removed from the Images row in Supported File Types and How It Works tables; added to the Passthrough row alongside TXT, CSV, etc.

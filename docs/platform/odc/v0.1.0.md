v0.1.0 - Initial release

Strips embedded metadata from uploaded files to prevent file metadata
injection attacks before files reach AI APIs or are stored.

SERVER ACTION
  StripFileMetadata(rawFile: BinaryData) -> FileMetadataResult

OUTPUT STRUCTURE: FileMetadataResult
  CleanFile (Binary Data)
    The file with all metadata removed. Safe to forward to AI APIs
    or store. Identical to the input when IsPassthrough is true.
  ExtractedMetadata (Text)
    JSON of every metadata entry found and removed. Keys vary by
    format: images use exif/iptc/xmp; PDFs use title/author/subject/
    keywords/creator/producer; OOXML documents use creator/
    lastModifiedBy/created/modified/title and more; audio/video use
    the tag fields present in the file. Returns "[]" when no metadata
    was found. Contains a processingError key if the audio/video
    engine could not parse the file.
  RemovedEntryCount (Integer)
    Total number of metadata entries removed. Zero when no metadata
    was present, the format is a passthrough, or the file could not
    be parsed.
  IsPassthrough (Boolean)
    True when the format has no supported metadata containers (e.g.
    TXT, CSV, JSON). The file is returned unchanged.

SUPPORTED FORMATS
  Images: JPEG, PNG, GIF, BMP, TIFF, WebP, TGA, and 100+ more
    Strips: EXIF, IPTC, XMP, ICC profiles, image comments
  PDF
    Strips: Title, Author, Subject, Keywords, Creator, Producer
  Office Open XML: DOCX, XLSX, PPTX
    Strips: Creator, LastModifiedBy, Created, Modified, Title,
            Subject, Description, Keywords, Category, Revision
  Audio: MP3, FLAC, OGG, WAV, M4A, WMA
    Strips: ID3 tags, Vorbis comments, all metadata atoms
  Video: MP4, MOV, AVI, MKV, WebM, WMV
    Strips: all metadata atoms and tags
  Plain text, CSV, JSON, XML, and other unrecognised formats
    Passthrough - file returned unchanged, IsPassthrough = true

NOTES
  Format is preserved: output is always in the same format as input.
  If an audio/video file cannot be parsed, the original file is
  returned unchanged and ExtractedMetadata contains a processingError
  audit note.
